# Detektif Gaya: Misteri di Sekitar Kita

Gim edukatif teka-teki 2D untuk siswa SD Kelas 4, topik IPAS — jenis-jenis gaya (gaya otot, gaya gesek, gaya magnet, gaya gravitasi, gaya pegas).

## Tentang Gim
Pemain berperan sebagai "detektif gaya" yang mencocokkan 15 pasangan kartu: aktivitas sehari-hari (bergambar ikon) dengan jenis gaya yang bekerja padanya. Setiap pasangan yang benar membuat kartu menghilang dan menyingkap sedikit demi sedikit pemandangan tersembunyi di baliknya. Setelah semua pasangan ditemukan, muncul rangkuman kelima jenis gaya sebagai penguatan materi.

## Cara Menjalankan
1. Buka file `index.html` langsung di peramban (browser), atau
2. Aktifkan GitHub Pages pada repository ini agar dapat dimainkan online (lihat Tahap 3 pada Lembar Kerja).

## Spesifikasi Teknis
- Satu file tunggal (`index.html`) berisi HTML, CSS, dan JavaScript.
- Tanpa library eksternal (hanya Google Fonts untuk tipografi).
- Efek suara dibuat sepenuhnya secara sintetis dengan Web Audio API — tidak ada file audio eksternal.
- Responsif untuk perangkat HP maupun laptop.

## Prompt AI yang Digunakan
Prompt final yang digunakan untuk menghasilkan gim ini tercantum pada Tahap 2.2 dokumen `Lembar Kerja Gim Edukatif Terisi.docx`.

## Tujuan Pembelajaran
1. Siswa mampu mengidentifikasi jenis-jenis gaya melalui contoh dalam kehidupan sehari-hari.
2. Siswa mampu mengelompokkan aktivitas sesuai jenis gaya yang bekerja padanya.
